# CAP Inbox — UI Asset Pack 4K

Paquete visual listo para implementación.

## Fuente canónica
- `brand/logos/svg/`: logos vectoriales para producción.
- `brand/logos/png/`: versiones raster de alta resolución.
- `screens/canonical/4k/`: pantallas finales principales 3840×2160.
- `screens/coverage/4k/`: todas las vistas/estados del blueprint en 3840×2160.
- `design-system/`: tokens de color, tipografía, radio y espaciado.
- `docs/`: PDF pantalla por pantalla y hoja de contacto.

## Implementación
No uses las capturas como fondos. Implementa los componentes en Vue/CSS y usa estas imágenes como referencia visual. Usa los SVG del logo dentro de la app. Inter debe cargarse desde el propio proyecto; no se incluye ningún archivo de fuente.

## Simetría visual
Mantén el mismo AppShell, topbar, sidebar, gutters, radios, botones, tipografía y comportamiento de estados en Inbox, Contactos, Campañas, Métricas, Equipo, Configuración y Diagnóstico.

## Paleta

Dark: #0f1720 / #131e29 / #182531 / #1e2d3a con Ink #f7f6f3.
